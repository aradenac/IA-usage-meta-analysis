# Evidence

This directory is the persistent evidence store for the meta-analysis.

Planned categories:

- `benchmarks/` — reproducible public benchmark snapshots/protocol notes.
- `vendor-docs/` — metadata and extracts/notes from official model/provider documentation.
- `field-signals/` — practitioner reports, issues, forums and small real-world bake-offs.
- `internal-tests/` — future company-run tests and traces.

Do not mirror copyrighted third-party documents wholesale unless redistribution is permitted. Prefer URLs, metadata, measured values, protocol descriptions, hashes/version identifiers, and short permitted extracts.
