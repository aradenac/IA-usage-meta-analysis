# Vendor documentation evidence

Use this folder for evidence derived from official model/provider/vendor documentation when a normalized row in `data/observations.json` is not enough.

Prefer storing:

- source URL and retrieval date;
- exact product/model/version;
- pricing snapshot and region/currency;
- benchmark protocol details;
- API/surface capabilities;
- data-handling / deployment information relevant to sovereignty;
- short permitted extracts or our own notes.

Do not mirror full copyrighted vendor documents unless redistribution is explicitly allowed.
