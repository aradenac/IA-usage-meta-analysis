# Internal tests

Future company tests should capture at minimum:

- business task ID and Definition of Done
- model + surface/harness + exact configuration
- success/failure
- API/service cost
- active human time
- autonomous wall-clock
- number/type of interventions
- input artifact classification (public/internal/client-sensitive)
- reproducibility details
- raw traces/logs where policy allows

Internal evidence should improve P(success), C_API and configuration-specific T_human,AI without changing the MetaScore definition.
